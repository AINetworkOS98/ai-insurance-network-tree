## 3) ลำดับการคำนวณในชีต `คำนวณภาษี` (แมปสูตรจริง)

```
แถว 3  เงินได้พึงประเมิน (1),(2)         = C3 … คัดลอกไปทุกคอลัมน์
แถว 4  เบี้ยประกันที่บริษัทจ่ายแทน        = D4 … (คอลัมน์ C ไม่มี)
แถว 5  ภาษีที่จ่ายแทน (ยกมาจากคอลัมน์ก่อน) = D5 = C29 · E5 = D29 · F5 = E5 + E30 …
แถว 6  รวมเงินได้พึงประเมิน              = SUM(แถว 3:5)
แถว 7  หักค่าใช้จ่าย                     = ช่องกรอก (ไฟล์ตั้งไว้ 100,000 = เพดาน 50% ของ 2.5 ล้าน)
แถว 8–23 หักค่าลดหย่อนตามจริง (ตนเอง 60,000, คู่สมรส, บุตร, พ่อแม่, ประกัน, กองทุน, กอช., ดอกเบี้ยบ้าน, Solar, อื่น ๆ)
แถว 24 เงินได้สุทธิ                      = แถว 6 − SUM(แถว 7:23)
แถว 25/27 บริจาคการศึกษา 2 เท่า / บริจาคทั่วไป (ไม่เกิน 10%)
แถว 28 เงินได้สุทธิเพื่อคำนวณภาษี        = แถว 26 − แถว 27
แถว 29 ภาษีที่คำนวณได้                   = แถว 52
แถว 30 ภาษีเพิ่มขึ้นจากคอลัมน์ก่อน        = แถว 29 − ภาษีคอลัมน์ก่อน
แถว 45–51 ภาษีแยกตามขั้น (IF ซ้อน 7 ชั้น, อัตราอ้าง $D$38:$D$44)
แถว 52 ภาษีรวม                          = SUM(แถว 45:51)
```

ภาษีของแต่ละขั้นในชีตเขียนเป็น `IF` ซ้อน (เช่น ขั้น 30%)
`=IF(สุทธิ<2000001,0,IF(สุทธิ>5000000,900000,IF(สุทธิ>2000001,(สุทธิ-2000000)*0.30)))`
⇒ เทียบเท่าการคูณความกว้างขั้นจริงตามตารางข้อ 1

## 4) "ออกภาษีให้ทุกทอด" (gross-up) — หัวใจของชีตนี้

บริษัทจ่ายเบี้ยประกันและภาษีแทนกรรมการ ⇒ ภาษีที่จ่ายแทนถือเป็นเงินได้ของกรรมการในรอบถัดไป

```
ให้ I = เงินได้พึงประเมิน, P = เบี้ยประกัน, D = ค่าใช้จ่าย + ค่าลดหย่อน, T(n) = ภาษีรอบ n
T(0) = ภาษีเมื่อยังไม่รวมเบี้ยประกัน            (คอลัมน์ C = 467,000)
เงินได้รวมรอบ n = I + P + T(n−1)
เงินได้สุทธิรอบ n = I + P + T(n−1) − D
T(n) = progressive_tax(เงินได้สุทธิรอบ n)
วนซ้ำจนผลต่าง < 0.01 บาท (ชีตใช้ 17 คอลัมน์ C–S)
```

จุดลู่เข้า (แก้สมการตรง ๆ ได้เลย ไม่ต้องวน):
`T = f(I + P − D + T)` — ตัวอย่าง I=2,500,000, P=500,000, D=160,000
`T = 365,000 + 0.30 × (840,000 + T)` ⇒ `T = (365,000 + 252,000) / 0.7 = 881,428.57`

**ผลลัพธ์เคสในไฟล์**

| รายการ | จำนวน (บาท) |
|---|---:|
| ภาษีเมื่อไม่มีเบี้ยประกัน (PIT กรรมการ) | 467,000.00 |
| ภาษีหัก ณ ที่จ่ายครั้งเดียว (รอบแรก) | 290,100.00 |
| ภาษีเมื่อออกให้ทุกทอด (ลู่เข้า) | 881,428.57 |
| เงินได้รวมสุดท้ายที่กรรมการได้รับ | 3,881,428.57 |
