# สแกนใบเสร็จด้วยมือถือ — วิธีใช้ + บันทึกทางเทคนิค

อัปเดต: 20 ต.ค. 2026 · ผู้ใช้ยืนยันว่าใช้งานได้แล้ว

## วิธีใช้ที่ได้ผล (จำลิงก์นี้)

```
https://ai-insurance-network-tree.vercel.app/documents?m=1&cam=1
```

1. เปิดลิงก์ข้างบนด้วย **Chrome** (Android) หรือ **Safari** (iPhone) — ไม่ใช่เบราว์เซอร์ใน LINE
2. อนุญาตสิทธิ์กล้องครั้งแรก
3. กล้องเปิดเองพร้อมถ่าย → กดชัตเตอร์ **ครั้งเดียว**
4. ระบบสแกนยอดเงินอัตโนมัติ → ตรวจผล → ยืนยันบันทึก

ติดตั้งเป็นแอป (แนะนำ ทำครั้งเดียว): กดปุ่ม **"ติดตั้งแอปสแกนใบเสร็จ"** ในหน้า หรือ ⋮ → เพิ่มลงในหน้าจอหลัก
หลังจากนั้นแตะไอคอนบนหน้าจอโฮม → กล้องพร้อมถ่ายทันที

## ทำไมใช้ใน LINE ไม่ได้

| สิ่งที่ลอง | ผล |
|---|---|
| กล้องสดในหน้าเว็บ (`getUserMedia`) | `NotAllowedError` — WebView ของ LINE ไม่ให้สิทธิ์กล้องกับเว็บ |
| `<input type="file" capture="environment">` | LINE เปิดคลังภาพ/ค้นรูปแทนกล้อง |
| `accept="image/*;capture=camera"` | เหมือนกัน — ยังเปิดคลังภาพ |
| ปุ่มที่ใช้ JS สั่ง `input.click()` | WebView เพิกเฉย (ไม่ถือเป็น user gesture) → เปลี่ยนเป็น `<label htmlFor>` แล้ว |

⇒ ใน LINE ใช้ได้เฉพาะ **"ถ่ายด้วยแอปกล้องของเครื่อง → กลับมาเลือกจากคลังภาพ → สแกน"** หรือกดปุ่ม **"🌐 เปิดใน Chrome"** ในกรอบเขียวของหน้าเว็บ

## สิ่งที่แก้ไว้ในโค้ด (อย่าลบ)

- `src/app/documents/page.tsx`
  - ตรวจ in-app browser → แสดงกรอบเขียว + ปุ่มเปิด Chrome (intent) และปิดปุ่มกล้องสดพร้อมคำอธิบาย (ไม่ซ่อนปุ่ม)
  - `?m=1` = เลย์เอาต์มือถือ · `?cam=1` = เปิดกล้องอัตโนมัติ + ถ่ายแล้วสแกนต่อทันที
  - ผูก `srcObject` ใน `useEffect([camOpen])` (overlay ต้อง mount ก่อน) + รอ `videoWidth>0` ก่อนถ่าย
  - ย่อรูปในเครื่อง (ด้านยาว 1600px, JPEG 0.85) ก่อนอัปโหลด + ดักไฟล์ HEIC
  - ถ้า multipart POST ล้ม → ส่ง **JSON base64** อัตโนมัติ (LINE WebView ตัด multipart)
  - แสดง `build: <commit>` ใต้หัวข้อเพื่อตรวจว่าเครื่องได้บิลด์ใหม่
- `src/app/api/ocr/route.ts` — รับได้ทั้ง multipart และ JSON base64
- `src/app/api/scan-diag/route.ts` — วินิจฉัยจากเครื่องผู้ใช้ (console.log เท่านั้น, ไม่แตะ DB/PII)
  อ่าน log: `node node_modules/vercel/dist/vc.js logs <prod-url> --since 6h --query "scan-diag" -j --limit 100 > vlogs.jsonl`
- `src/app/manifest.ts` + `public/icon-{192,512,maskable-512}.png` — PWA (`start_url=/documents?m=1&cam=1`)
