# ระบบบริหารเครือข่าย 1 แตก 5 — เชื่อมต่อสายงานทุกระดับอัตโนมัติ (1×5 Autopilot)

ระบบ **จริง** (ไม่ใช่การจำลอง): ตรวจเงื่อนไข → คัดสมาชิกที่ไม่ผ่าน → เลื่อนผู้มีคุณสมบัติขึ้นแทน →
จัดสายงาน 1 แตก 5 → อัปเดตโครงสร้างทุกระดับ → แจ้งเตือนอัตโนมัติ โดยเก็บ Log ทุกการเปลี่ยนแปลง

- Dashboard (เมนูใหม่ ต่อจาก “สอบถามรายละเอียด”): **/network/1x5-autopilot**
- เอกสาร PDF (ลิงก์มุมบนขวาของหน้า): **/docs/net-1x5-autopilot.pdf** (ต้นฉบับ `docs/net-1x5-autopilot.html`)
- ข้อมูลที่ใช้ = **ข้อมูลจริง** ในตารางจริง (`User · TreeNode · TreePlacement · PerformanceLedger · ReceiptFile · AuditLog · PlacementRun/Entry · PlacementHistory · RankHistory · MembershipStatusHistory · ReceiptSettings · Notification · EventOutbox`) — ไม่ใช้ตาราง `sim_*` เลย

## ลำดับการทำงาน (7 ขั้น) — ตามสเปก
1. **ตรวจสอบเงื่อนไข**: สถานะสมาชิก · ใบเสร็จ/ดาวน์โหลดตามกำหนด · ยอดรับรองขั้นต่ำ · ใบเสร็จรอตรวจ (ห้ามใช้เป็นเหตุคัด) · คุณสมบัติเลื่อนตำแหน่ง
2. **ระบุสมาชิกที่ไม่ผ่าน** (แจกแจงเหตุผลรายคน)
3. **นำออกจากตำแหน่ง**: ตั้งสถานะ “ไม่ผ่านเงื่อนไข” (SUSPENDED) · ปิดจุดในผัง (isActive=false, คงสายงานเดิม) · **ปลดช่องในผัง** · บันทึกประวัติ + Log + แจ้งเตือน
4. **ค้นหาผู้มีคุณสมบัติครบ** + จัดลำดับความสำคัญ (ใกล้ตำแหน่งว่าง → ผลงานรับรอง → อาวุโส)
5. **เลื่อนขึ้นแทนตำแหน่งว่าง** — *ตรวจคุณสมบัติก่อนทุกครั้ง; ผู้ไม่ผ่าน = ระบบปฏิเสธการเลื่อน*
6. **ปรับสายงาน 1 แตก 5** (เติมช่องว่างจากคิวรอจัดวาง · ตรวจผู้แนะนำ/สมาชิกในสายงาน)
7. **Recalculate + อัปเดตทุกระดับ**: แก้ระดับ/จำนวนลูกตรงทุกโหนด + บันทึก Log (ตรวจสอบย้อนหลังได้)

## กฎเหล็กที่บังคับในโค้ด (`src/lib/net1x5.ts`)
- ห้ามเลื่อนสมาชิกที่ยังไม่ผ่านเงื่อนไข
- ห้ามปล่อยตำแหน่งว่างถ้ามีผู้มีคุณสมบัติครบ (ถ้าไม่มี → แจ้งผู้ดูแล + ตรวจซ้ำทุกรอบ)
- ห้ามตัดบัญชีผู้ดูแลระบบ (ยกเว้นอัตโนมัติเสมอ)
- ห้ามตัดซ้ำคนที่ถูกนำออกไปแล้ว (SUSPENDED/RESIGNED)
- ห้ามคัดคนที่มีใบเสร็จ “รอตรวจ” (กันความผิดพลาดจาก OCR/ผู้ตรวจล่าช้า)
- เพดานต่อรอบ (กันรอบทำงานยาวเกินเวลาเซิร์ฟเวอร์): คัดออก 10 · เลื่อนตำแหน่ง 3 · แจ้งเตือนรายคน 4 → ที่เหลือดำเนินการรอบถัดไปอัตโนมัติ

## API (`/api/net/1x5/*`)
| เส้นทาง | ใช้ทำอะไร | สิทธิ์ |
|---|---|---|
| `GET /state` | สถานะ/เงื่อนไข/ตำแหน่งว่าง/ผู้มีสิทธิ์/Log ล่าสุด | สมาชิกที่ล็อกอิน (ชื่อถูกปกปิดถ้าไม่ใช่ผู้ดูแล) |
| `POST /run` `{mode:'preview'\|'apply', period?, idempotencyKey?}` | รันวงจรตรวจ (preview) หรือรันจริง (apply) | preview = สมาชิก · apply = ผู้ดูแลระบบ หรือ `Bearer <CRON_SECRET>` |
| `GET\|POST /rules` | อ่าน/แก้กติกา (เก็บใน DB) | อ่าน = สมาชิก · แก้ = ผู้ดูแลระบบ |
| `POST /seed` `{action:'create'\|'purge', layers}` | สร้าง/ลบเครือข่ายทดสอบ (โดเมน `@ai-insurance-test.local`) | ผู้ดูแลระบบ |

กติกาเก็บที่ `ReceiptSettings.settings.net1x5` — แก้จาก Dashboard ได้โดยไม่ต้องแก้โค้ด ทุกครั้งที่แก้มี Audit Log

## n8n Workflows (`workflows/`)
| ไฟล์ | ทำงาน |
|---|---|
| `1x5-01-deadline-and-run.json` | ทุก 15 นาที: ตรวจกำหนดเวลา + รัน apply (มี idempotencyKey) |
| `1x5-02-daily-condition-check.json` | ทุกวัน 06:00: ตรวจเงื่อนไข (preview) → สรุปรายงาน → ถ้ามีคนไม่ผ่านจึง apply |
| `1x5-03-refill-vacancy.json` | ทุก 30 นาที: เติมตำแหน่งว่าง/เลื่อนแทน (กติกา “ห้ามทิ้งตำแหน่งว่าง”) |
| `1x5-04-webhook-run.json` | Webhook สั่งรันทันที `POST /webhook/net-1x5/run` |
| `1x5-05-audit-watch.json` | ทุก 1 ชั่วโมง: เฝ้า Audit Log + เตือนตำแหน่งว่างค้าง (`env ALERT_WEBHOOK_URL`) |

ติดตั้ง: `python scripts/import_1x5_workflows.py` (เขียน n8n SQLite ตรง + export สำรองที่ `n8n/_exports/`) แล้วรีสตาร์ท n8n
n8n ต้องมี env: `CRON_SECRET` (ต้องตรงกับแอป), `APP_BASE_URL` (ค่าเริ่มต้น = production), `ALERT_WEBHOOK_URL` (ไม่บังคับ)

## ทดสอบจริงแล้ว (กับฐานข้อมูลจริง)
- `GET /state` → อ่านกติกา/กำหนดเวลาจริง
- `POST /seed` (2 ชั้น) → 31 คน · สายงาน 30 ตำแหน่ง · ใบเสร็จ 25 ใบ
- `POST /run preview` → 32 คน: ผ่าน 20 · ไม่ผ่าน 12 · กันการคัด (รอตรวจ) 1
- `POST /run apply` → คัดออก 12 (SUSPENDED + ปิดจุดในผัง + PlacementHistory=removed) · เลื่อนตำแหน่ง 4 · Recalculate 22 โหนด ·
  AuditLog `net1x5.*` ครบ · PlacementRun สถานะ `completed`
- ค่าเริ่มต้นของระบบคือ **ปิด “คัดออกอัตโนมัติจริง”** (ตรวจแล้วรอผู้ดูแลอนุมัติ) — เปิดเมื่อพร้อมใช้งานจริง
