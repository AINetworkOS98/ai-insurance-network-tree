ระบบบริหารเครือข่าย 1 แตก 5
เชื่อมต่อสายงานทุกระดับอัตโนมัติ

เอกสารสรุประบบ (System Document) — ระบบจัดโครงสร้างสายงาน เชื่อมต่อสมาชิก บริหารตำแหน่งทุกระดับ ตรวจสอบเงื่อนไข คัดสมาชิกที่ไม่ผ่าน เลื่อนสมาชิกที่ผ่านเงื่อนไขขึ้นแทน และเชื่อมต่อสายงานอย่างต่อเนื่องโดยไม่ต้องให้ผู้ดูแลระบบจัดตำแหน่งด้วยมือ
เข้าถึง Dashboard: /network/1x5-autopilot · เมนูอยู่ในแถบเมนูบน ต่อจาก “สอบถามรายละเอียด”

1. หลักการทำงาน

  1. สมาชิก 1 คน แตกสมาชิกต่อได้ 5 คน — สมาชิกแต่ละคนมีตำแหน่งและสายงานของตนเอง เมื่อมีสมาชิกใหม่ ระบบตรวจตำแหน่งที่ว่างและจัดวางเข้าสายงานอัตโนมัติ (BFS จากผู้แนะนำลงไปทุกระดับ) และเชื่อมโยงสายงานตั้งแต่ระดับบนลงไปต่อเนื่อง
  2. ระบบตรวจสอบเงื่อนไขโดยอัตโนมัติ — ตรวจสถานะสมาชิก · ตรวจการดาวน์โหลด/ยืนยันใบเสร็จตามเงื่อนไข · ตรวจวันและเวลาที่ต้องดำเนินการ · บันทึกประวัติการดำเนินการของสมาชิกทุกคน
  3. กรณีสมาชิกไม่ปฏิบัติตามเงื่อนไข — ระบบตั้งสถานะ “ไม่ผ่านเงื่อนไข” (SUSPENDED) นำออกจากตำแหน่งตามกติกาโดยอัตโนมัติ และห้ามให้ตำแหน่งว่างค้างอยู่ในโครงสร้าง
  4. การเลื่อนตำแหน่งแทนอัตโนมัติ — เมื่อมีตำแหน่งว่าง ระบบตรวจสมาชิกที่มีคุณสมบัติครบถ้วนจากตำแหน่งถัดไป แล้วเลื่อนขึ้นมาแทนโดยอัตโนมัติ
  5. การเชื่อมต่อสายงาน — หลังเปลี่ยนตำแหน่ง ระบบ Recalculate โครงสร้างเครือข่ายทั้งหมด และตรวจความสัมพันธ์ของผู้แนะนำ · ผู้แนะนำระดับบน · สมาชิกในสายงาน · ตำแหน่ง 1 แตก 5 · ตำแหน่งที่ว่าง · สมาชิกที่มีสิทธิ์เลื่อนตำแหน่ง
  6. ทำงานแบบ Real-time — เมื่อสถานะสมาชิกเปลี่ยน ระบบปรับโครงสร้างและตำแหน่งที่เกี่ยวข้องอัตโนมัติ (Dashboard อัปเดตทุก 8 วินาที · n8n ตรวจทุก 15/30 นาที ทุกวัน 06:00 และทุกชั่วโมง)

2. ลำดับการทำงานอัตโนมัติ (7 ขั้น)

ขั้น 1 · ตรวจสอบเงื่อนไขสถานะ · ใบเสร็จ · ยอดรับรอง · กำหนดเวลา · ใบเสร็จรอตรวจ
ขั้น 2 · ระบุสมาชิกที่ไม่ผ่านแจกแจงเหตุผลรายคน + กันการคัดกรณีรอตรวจ
ขั้น 3 · นำออกจากตำแหน่งตั้งสถานะไม่ผ่านเงื่อนไข · ปิดจุดในผัง · บันทึกประวัติ
ขั้น 4 · ค้นหาผู้มีคุณสมบัติครบจัดลำดับความสำคัญตามกติกาที่ตั้งไว้
ขั้น 5 · เลื่อนขึ้นแทนผู้ผ่านเงื่อนไขเท่านั้น · ห้ามเลื่อนคนไม่ผ่าน
ขั้น 6 · ปรับสายงาน 1:5เติมช่องว่าง · ตรวจผู้แนะนำ/สมาชิกในสายงาน
ขั้น 7 · อัปเดตทุกระดับ + LogRecalculate ระดับ/จำนวนลูกตรง · Audit Log ครบ

3. เกณฑ์ที่ระบบใช้ตัดสิน (แก้ได้จากหน้าจอ เก็บในฐานข้อมูล)

เกณฑ์ค่าเริ่มต้นความหมาย
รอบที่ประเมินเดือนปัจจุบัน (YYYY-MM)รอบบัญชีที่ใช้ตรวจเงื่อนไขและบันทึกประวัติ
ต้องส่งใบเสร็จภายใน15 วันหลังปิดรอบเกินกำหนด = ไม่ผ่านเงื่อนไข
วัน/เวลาที่ต้องดำเนินการวันที่ 25 เวลา 18:00 น.ใช้กับตัวนับถอยหลังบน Dashboard และรอบทำงานของ n8n
ยอดรับรองขั้นต่ำต่อรอบ฿20,000อ่านจาก PerformanceLedger (สถานะ active) ของรอบนั้น
ผ่อนผันสมาชิกใหม่30 วันสมาชิกใหม่ยังไม่ถูกคัดออกระหว่างผ่อนผัน
คัดออกอัตโนมัติจริงปิด (ตรวจแล้วรออนุมัติ)เปิดเมื่อพร้อม — ระบบจึงตัดสมาชิกออกจริงอัตโนมัติ
เลื่อนตำแหน่งแทนอัตโนมัติเปิดเลื่อนผู้ผ่านเงื่อนไขขึ้นแทนตำแหน่งว่างทันที
ห้ามทิ้งตำแหน่งว่างเปิดเติมช่อง 1:5 ทันทีที่ว่าง ถ้าไม่มีผู้มีคุณสมบัติ จะแจ้งเตือนและตรวจซ้ำทุกรอบ
ลำดับความสำคัญใกล้ตำแหน่งว่างที่สุด → ผลงานรับรองสูงสุด → อาวุโสใช้เมื่อมีผู้ผ่านเงื่อนไขหลายคน

เกณฑ์ทั้งหมดถูกเก็บในฐานข้อมูลจริง (ตาราง ReceiptSettings.settings.net1x5) แก้จาก Dashboard ได้โดยไม่ต้องแก้โค้ด และทุกครั้งที่แก้จะถูกบันทึก Audit Log

4. กฎสำคัญที่ระบบบังคับในโค้ด

  • ห้ามเลื่อนสมาชิกที่ยังไม่ผ่านเงื่อนไข — ฟังก์ชันเลื่อนตำแหน่งจะปฏิเสธทันทีถ้าผู้รับการเลื่อนไม่ผ่านเงื่อนไขครบ
  • ห้ามปล่อยตำแหน่งว่าง — ถ้ามีสมาชิกที่มีคุณสมบัติครบ ระบบต้องเติม/เลื่อนขึ้นแทนทันที ถ้าไม่มี ระบบแจ้งเตือนผู้ดูแลและตรวจซ้ำอัตโนมัติทุกรอบ (ไม่ค้างเงียบ)
  • ต้องตรวจสอบคุณสมบัติก่อนเลื่อนตำแหน่งทุกครั้ง
  • ต้องเก็บ Log ทุกการเปลี่ยนแปลง — Audit Log + PlacementHistory + PlacementRun/Entry + RankHistory + MembershipStatusHistory และตรวจสอบย้อนหลังได้จากแท็บ Log บน Dashboard
  • ถ้ามีผู้ผ่านเงื่อนไขหลายคน ใช้ลำดับความสำคัญที่ระบบกำหนดไว้ (เลือกได้ 3 แบบ)
  • ทุกครั้งที่มีการเปลี่ยนตำแหน่ง ระบบปรับโครงสร้างสายงานที่เกี่ยวข้องอัตโนมัติ (Recalculate ระดับ + จำนวนลูกตรง)
  • ใบเสร็จที่ยังรอตรวจ ห้ามใช้เป็นเหตุคัดออก — กันความผิดพลาดจาก OCR/ผู้ตรวจล่าช้า

5. สถาปัตยกรรม: n8n + ฐานข้อมูล + Dashboard

ชั้นรายละเอียด
เครื่องยนต์ (Engine) src/lib/net1x5.ts — ตรวจเงื่อนไข · คัดออก · ค้นหาผู้มีคุณสมบัติ · เลื่อนตำแหน่ง · เติมช่อง 1:5 · Recalculate · แจ้งเตือน · บันทึก Log (ทำงานบนข้อมูลจริงเท่านั้น ไม่ใช้ข้อมูลจำลอง)

GET|POST /api/net/1x5/rules — อ่าน/แก้กติกา (ผู้ดูแลระบบ)

6. ความปลอดภัยและความถูกต้องของข้อมูล

  • การคัดออก/เลื่อนตำแหน่งเป็น “งานเขียนข้อมูลจริง” — ต้องเป็นผู้ดูแลระบบหรือ n8n ที่มี CRON_SECRET เท่านั้น และมีค่า idempotencyKey กันรันซ้ำ
  • โหมด ตรวจสอบ (preview) ใช้ฟรีสำหรับทุกคนที่ล็อกอิน — ไม่แก้ข้อมูลจริงแม้แต่แถวเดียว
  • ค่าเริ่มต้นปิด “คัดออกอัตโนมัติจริง” — เพื่อให้ผู้ดูแลเห็นผลตรวจก่อนตัดสินใจเปิด
  • สมาชิกที่ไม่ใช่ผู้ดูแลจะเห็นชื่อสมาชิกแบบปกปิดบางส่วน (ยังตรวจสอบด้วยรหัสสมาชิกได้)
  • เครือข่ายทดสอบใช้โดเมนอีเมล @ai-insurance-test.local เท่านั้น ลบได้ทุกเมื่อ และไม่แตะข้อมูลสมาชิกจริง
  • ระบบไม่ใช้ข้อมูลจำลอง (sim_*) ปนกับข้อมูลจริง — Dashboard ระบุชัดว่าเป็น “ข้อมูลจริงในฐานข้อมูล”

7. การใช้งานจริง (ขั้นตอนสั้น)

  1. เข้าสู่ระบบ → เมนู “ระบบ 1 แตก 5 อัตโนมัติ” (ต่อจาก “สอบถามรายละเอียด”)
  2. กด “ตรวจสอบเงื่อนไข (ยังไม่แก้ข้อมูล)” เพื่อดูผลตรวจ/ตำแหน่งว่าง/ผู้มีสิทธิ์ก่อน
  3. ปรับ “กติกา” ให้ตรงนโยบาย เช่น จำนวนวันส่งใบเสร็จ, ยอดรับรองขั้นต่ำ, ลำดับความสำคัญ
  4. ตั้ง คัดออกอัตโนมัติจริง = เปิด แล้วกด “รันจริง” (หรือปล่อยให้ n8n รันตามรอบ)
  5. ตรวจย้อนหลังได้ที่แท็บ Log ตรวจสอบย้อนหลัง — ทุกการคัดออก/เลื่อนตำแหน่ง/เติมตำแหน่งว่างมีบันทึกครบ
เอกสารนี้สร้างจากระบบจริง (โค้ด + ฐานข้อมูลของโปรเจกต์ ai-insurance-network-tree) · ตัวเลข/เกณฑ์ทั้งหมดเป็นค่าตั้งต้นของระบบ ไม่ใช่การรับประกันรายได้หรือผลลัพธ์
